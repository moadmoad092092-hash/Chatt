# شات العرب

مساعد دردشة عربي بواجهة RTL وخادم Node.js يربط الرسائل بـ Google Gemini عبر مكتبة `@google/genai`. الواجهة تعرض الرد تدريجيًا عبر SSE، وتحفظ سجل المحادثات محليًا في متصفح المستخدم.

## المتطلبات والتشغيل

يتطلب المشروع Node.js 20 أو أحدث. بعد فك الضغط شغّل:

```bash
npm install
cp .env.example .env
npm start
```

ثم افتح `http://localhost:3000`. ضع مفتاح Gemini في `.env` فقط داخل `GEMINI_API_KEY`. لا تضعه في `public/` أو في ملفات JavaScript التي تصل إلى المتصفح، ولا ترفع `.env` إلى GitHub أو إلى ملف ZIP.

يمكن تغيير `PORT` و`GEMINI_MODEL` وقيود المعدل من `.env`. النموذج الافتراضي هو `gemini-3.8-flash`، وهو نموذج Stable ظاهر في قائمة نماذج Gemini الرسمية وقت إعداد هذه النسخة. راجع وثائق Google عند النشر لأن توفر النماذج والحصص مرتبطان بمشروع Google ومفتاحه.

## الميزات المنفذة

تدعم الواجهة محادثة جديدة، وسجلًا محفوظًا محليًا، وحذف المحادثات، ونسخ الإجابات والأكواد، وإيقاف التوليد، والبث التدريجي، وحالات الاتصال والأخطاء، وتصميمًا متجاوبًا للهواتف والكمبيوتر. يحافظ الخادم على سياق آخر 40 رسالة كحد أقصى، ويقص كل رسالة إلى 12,000 حرف، ويطبق تحديد معدل في الذاكرة لكل عنوان IP.

لا يتضمن المشروع حاليًا البحث المباشر في الإنترنت أو رفع الملفات أو تسجيل الدخول وقاعدة بيانات. لذلك لا يدّعي المساعد استخدام الإنترنت ما لم تُضف أداة بحث فعلية لاحقًا.

## الاختبار

تم اختبار التشغيل المحلي، واستجابة `/api/health`، وحالة `/api/status`، ورفض طلب الدردشة عند غياب المفتاح، وفحص بناء JavaScript. اختبار الرد الحقيقي والبث من Gemini يحتاج مفتاحًا صالحًا في بيئة التشغيل، ولا يُعد ناجحًا قبل توفيره.

## النشر

عند النشر استخدم متغيرات أسرار المنصة لإضافة `GEMINI_API_KEY`، ولا تضع المفتاح في مستودع عام أو ملف ZIP. شغّل الخادم خلف HTTPS، واضبط proxy موثوقًا إذا كنت تعتمد على `X-Forwarded-For` لتحديد المعدل.

المراجع الرسمية: [Gemini models](https://ai.google.dev/gemini-api/docs/models) و[Text generation and streaming](https://ai.google.dev/gemini-api/docs/text-generation).
